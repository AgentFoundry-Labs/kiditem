## 1. 화면 구조 — iframe 탭 백오피스

메뉴를 누르면 `iframe#tabFrame_N` 이 하나씩 늘어난다.

| 메뉴 | 경로 |
|---|---|
| A101. 상품등록 | 신규 등록 |
| **A201. 상품관리** | `/product/productManagerList` — jqGrid `#prdGridList`, **조회결과 451건** |

목록 행의 버튼이 `window.open` 팝업을 연다:

- `prdDtlWinPop2(업체상품코드, …)` → **상품정보** ⭐ 화면 제목이 **"상품등록"** 이다 → **신규 ≡ 수정**
- `prdDtlWinPop(업체상품코드, 'cnts')` → **상세정보**(상세설명 + 고시)
- `prdOptWinPop(업체상품코드)` → 옵션
- `prdDtlWinPop2(코드, null, null, false, true)` → **복사** 등록

⚠️ 팝업이 `window.open` 이라 확장이 붙으려면 **그 창에 주입**하거나 `window.open` 을
가로채야 한다. 리서치 때는 `window.open` 을 후킹해 같은 탭 iframe 으로 띄워 읽었다.

## 2. ⭐ 하프클럽 + 보리보리, 한 백오피스

검색 조건의 `사이트` 가 **전체 / 하프클럽 / 보리보리** 다. 실측물은 `보리보리` 전용
(`siteCd`). ESM(G마켓·옥션)처럼 한 화면에서 두 몰을 다루지만, **상품마다 사이트를
고르는 방식**이라 ESM 처럼 한 번에 둘이 되지는 않는다 — 확인 필요.

## 6. ⭐⭐ 상세설명 — 보리보리에 직접 올릴 수 있다

에디터는 **Summernote**(`.note-editable`), 뒷단 textarea 가 **`prdDescContClob`**.

실측 등록물의 값:

```html
<center><img src="https://kiditem.diskn.com/S8brNL1Xs4"></center>
```

**지금은 diskn(키즈노트 호스팅) 주소를 쓰고 있다.** 하지만 툴바에 **`사진` 버튼**
(`note-icon-picture`)이 있고 `input[type=file][name="files"][accept="image/*"][multiple]`
가 함께 있다 → **보리보리 자체 업로드가 가능하다.**

⚠️ ESM 에서 배운 것: 남의 몰(키즈노트) 로그인이 풀리면 등록이 통째로 막힌다.
**보리보리도 자체 업로드를 주 경로로 쓴다.**

## 9. 남은 확인거리

1. 신규 등록(A101) 화면이 이 팝업과 같은 폼인지 — 값만 빈 것인지.
2. `siteCd`(하프클럽/보리보리)를 둘 다 고를 수 있는지.
3. 고시 `NO140` 을 고르면 뜨는 줄들의 이름.
4. Summernote `사진` 버튼이 여는 업로드 엔드포인트.
5. 저장 버튼 이름과 승인 절차(그리드에 `승인완료` 상태가 있었다).
