# 통합 Sellpia 재고 연결 모달 설계

## 목표

상품 매칭 센터의 상품, 옵션, Sellpia 재고 연결 작업을 하나의 모달로 합친다. 운영자는 다른 화면으로 이동하지 않고 현재 상품 행에서 필요한 모든 연결을 완료한다.

## 화면

- 상품 행 상태는 `Sellpia 재고 연결 필요`와 `연결 완료`만 사용한다.
- 상품 미연결, 옵션 미연결, 레시피 미구성은 모두 `Sellpia 재고 연결 필요`로 합산한다.
- 행의 `Sellpia 재고 연결` 버튼이 단일 모달을 연다.
- 기존 상품별 펼침 영역, 상품 연결 모달, 옵션 연결 모달, Sellpia 후보 모달, 상품 상세 이동 버튼은 제거한다.
- 상태 필터는 `전체`, `Sellpia 재고 연결 필요`, `연결 완료`만 제공한다.

## 모달 흐름

1. 채널 상품에 연결할 KidItem 상품을 검색하고 확정한다.
2. 같은 모달에서 각 채널 옵션에 연결할 KidItem 옵션을 검색하고 확정한다.
3. 연결된 옵션의 Sellpia 재고 구성은 같은 모달에서 검색하고 수량을 입력해 저장한다.
4. 각 저장 후 목록과 모달 데이터를 갱신하며 모달은 닫지 않는다.

기존 연결도 같은 모달에서 변경할 수 있다. 상품 연결을 변경하면 서버가 보장하는 기존 하위 옵션 연결 정리 규칙을 그대로 따른다.

## 데이터와 안전성

- 상품/옵션 확정은 기존 Channels API를 사용한다.
- Sellpia 후보 검색과 레시피 저장은 기존 Products API를 사용한다.
- 레시피 저장 시 현재 구성 전체를 `expectedRecipe`로 전송해 동시 수정을 감지한다.
- 재고 수량 자체는 편집하지 않고, 옵션 1개 생산에 필요한 양의 정수 구성 수량만 저장한다.
- 조직 범위는 세션에서 결정하며 클라이언트가 `organizationId`를 보내지 않는다.

## 완료 조건

상품이 연결되고, 수집된 모든 옵션이 운영 옵션에 연결되며, 모든 옵션의 레시피 상태가 `matched`일 때만 `연결 완료`로 표시한다. 그 외 모든 상태는 `Sellpia 재고 연결 필요`다.

## 오류 처리

후보 조회 오류와 저장 오류는 모달 안에 표시한다. 409 동시 수정 오류는 새로고침 후 다시 확인하도록 안내하며, 성공한 이전 단계는 유지한다.

## 검증

- 테이블 테스트로 두 상태와 단일 버튼, 기존 펼침/개별 버튼 제거를 검증한다.
- 모달 테스트로 상품 → 옵션 → Sellpia 재고 저장을 한 모달 안에서 수행하는지 검증한다.
- 페이지 테스트로 단순화된 상태 필터와 단일 모달 연결을 검증한다.
- product-hub 집중 테스트와 web 전체 빌드를 실행한다.
