실측 2026-09-11. 떠리몰 = NHN커머스 샵바이 임대몰(`thirtymall.com`, `mallNo 78859`).
입점 관리는 **샵바이 파트너어드민**(`partner.shopby.co.kr`), 파트너사 `㈜거영I&D`(`partnerNo 148393`).

- 목록 `/product/list` · 신규 `/product/add` · 수정 `/product/edit?mallProductNo=…&planType=PREMIUM`
  (목록 칸의 링크 `/product/edit/{번호}?planType=` 는 직접 열면 "페이지를 찾을 수 없습니다").
- 등록물 **479개**(2024-07-12 ~ 2025-11-24) 목록 전체 + 수정 화면 셋을 읽었다:
  `132154869` 야광 안테나 지시봉 (24개) · `132154733` 우파루팡 반짝 슈가 말랑이 (12개) ·
  `132022199` 샤이닝 반짝이 풀펜 (12개).

## 1. 화면 구조 — 겉과 속이 다른 도메인

| 층 | 주소 | 무엇 |
|---|---|---|
| 겉 | `partner.shopby.co.kr/product/add` | Vue SPA 껍데기(메뉴·제목) |
| 숨은 프레임 | `partner-remote.shopby.co.kr/?serviceType=PARTNER` | 0×0, 세션 다리 |
| **폼** | `partner-remote.shopby.co.kr/product/management/single/add?serviceType=PARTNER` | **React 앱**, 2904×1798 iframe |

⚠️ **폼 주소를 바로 열면 칸이 하나도 안 그려진다**(칸 0개 · API 0건 — 인증을 겉이 넘겨준다).
그래서 확장은 겉을 열고 모든 프레임에 넣되, 폼 프레임에서만 일한다(`frameUrlIncludes`).
iframe 은 겉 로딩이 끝난 **뒤에** 붙으므로 서비스워커가 그 프레임이 생길 때까지 먼저 기다린다.

데이터는 `admin-api.e-ncp.com`(헤더 `accesstoken`) — 우리는 부르지 않는다. 폼이 알아서 부른다.

## 2. ⭐ 칸에 이름이 없다 — 줄 제목이 손잡이

폼은 `<table>` 의 `th`(줄 제목) + `td`(칸)다. `input` 에 `name`·`id` 가 없고 클래스는 해시
(`Product_price-input__htgJ9`). 쓸 수 있는 손잡이는 **줄 제목**(`상품명`, `판매가`, …)과 몇 개의
`data-cy`(`productName`, `standardCategory`, `categorySearcherAutoComplete`) 뿐이다.

⚠️ 앞이 같은 줄 제목이 있다: `상품 상세(상단)` · `상품 상세` · `상품 상세(하단)`. **정확히 같은**
글자만 집는다.

## 4. ⭐ 가격 — 판매가 − 즉시할인 = 즉시할인가

화면 실측: 판매가 `8000` + 즉시할인 `2940`(원) → **즉시할인가 5,060 · 공급가 4,301**
(파트너 수수료 15%, 칸 잠김). 등록물이 전부 이 모양이라 우리는
**판매가 = 정상가, 즉시할인 = 정상가 − 우리 판매가** 로 넣는다. 즉시할인가가 우리 판매가가 된다.
등록물의 40% 할인 폭은 따라 하지 않는다 — 우리 정상가를 쓴다.

## 5. 검색해서 고르는 칸 — 담당자 · 표준/전시 분류 · 브랜드

분류는 `select`(`SWITCH_TO_PICKER` 카테고리 찾기 / `SWITCH_TO_SEARCH` 검색) + 자동완성 칸.
검색칸에 넣으면 **같은 줄 안에** `ul > li` 목록이 뜬다. 실측:

- 표준카테고리 ← `완구` : `출산/육아>완구/매트>놀이방매트`, `…>RC/작동완구>RC카` … (`>` 로 이은 전체 경로)
- 담당자 ← `노영우` : `노영우(nogoon92)`
- 브랜드 ← `kiditem` : `kiditem`

그래서 빌더는 `{줄 제목, 검색어, 고를 글자}` 를 준다. 검색어는 분류의 끝 이름, 고를 글자는 목록에
뜨는 그대로다.

## 7. ⭐ 상세설명 — Summernote

`상품 상세` 줄의 라디오를 `USE_CONFIG_VALUE`(사용함)로 바꾸면 Summernote(`div.note-editor`)가 생긴다.
jQuery 가 전역에 없어(`window.jQuery` undefined) `summernote('code', …)` 로 넣을 수 없다.
툴바 **그림 버튼** → `그림 삽입` 창에 `input.note-image-input`(file, multiple). 그 칸에 파일을 넣으면
몰이 받아 그림을 넣는다 — 몰 서버에 올라가는지(`https` 주소)는 라이브로 확인한다.

등록물은 diskn 이었지만 **몰 편집기로 올린다** — 남의 몰 세션에 기대지 않는다(ESM 교훈).

## 8. 상품정보제공고시 — 새 창

`사용함` → `등록` 을 누르면 **새 창**(`/popup/product-information-disclosure?sessionId=…`, 그 안에
또 `partner-remote` iframe)이 뜬다. 창이 따로라 확장은 거기까지 가지 않는다. 라디오만 `사용함` 으로
두고, 등록물 값(기타 재화 · 상세설명참조 ×3 · 중국 · KY I&D)을 사람이 넣도록 안내한다.

## 9. 배송

`배송 템플릿` 은 네이티브 `select`, 글자가 `option` 의 `label` 속성에 있다(`textContent` 는 비어 있음).
`기본 - 고정배송비(기본값)` · `금액별` · `수량별` · **`배송비무료`**. 번호는 계정마다 달라 글자로 고른다.

## 10. 붙인 방법

- 빌더 `thirtymall-registration-form.ts` — `tableFields`(줄 제목→값) · `tableRadios` · `tableSelects` ·
  `tablePicks`(검색·고르기) · `imageGroups`(main/additional/list) · `detailUploads`.
- 어댑터 `thirtymall.adapter.ts`(`mallKey: 'thirtymall'`) — 수량 · 표준분류 · 전시분류 · 담당자.
- 확장 SPEC `thirtymall` + 범용 장치: `frameUrlIncludes`(폼 프레임에서만 일함) + 서비스워커의 프레임
  기다리기, `tableForm`(줄 제목 칸·검색 고르기·select label·`이미지 추가`·Summernote 그림 업로드).
- 호스트 권한 `partner.shopby.co.kr` · `partner-remote.shopby.co.kr`(폼 프레임에 넣으려면 필요).

## 11. 라이브 실증(확장의 채움 함수 그대로, 빈 신규 폼)

`pageFunctions.fillMallProductForm` 을 실제 페이로드(서비스워커가 만든 그대로, 이미지 data URL 포함)로
폼 프레임에서 돌렸다. 결과 `ok`, **경고 0**, 채우는 동안 같은 문서 유지:

담당자 노영우(nogoon92) · 표준 `생활/건강>…>데코용품` · 전시 `생활/주방>…>완구용품` · 브랜드 kiditem ·
배송 템플릿 배송비무료 · 옵션 N · 인증정보 상세페이지 별도 표기 · 고시 사용함 · 상품명 · 판매가 8,000 ·
즉시할인 2,940 → 즉시할인가 5,060 / 공급가 4,301 · 재고 999 · 검색어 · 대표/추가/리스트 이미지 각 1장 ·
상세설명 그림(몰 편집기).

- 이미지는 파일을 넣는 즉시 `POST storage.e-ncp.com/images` 로 올라가 `//shopby-images.cdn-nhncommerce.com/…`
  (**스킴 없는 주소**)로 바뀐다. 상세설명 그림도 같은 곳이다 — 처음에 `https:` 만 성공으로 봐서 15초를
  헛기다렸다.
- 분류·브랜드는 고른 뒤에도 **목록이 떠 있다**. '목록이 닫혔나' 로 보면 멀쩡한 선택을 실패로 알린다 →
  목록 밖(칩·표 줄·글자칸)에 값이 생겼는지 본다.
- 표준분류를 바꾸면 화면이 "원산지, 인증정보, 카테고리수수료, 성인인증 사용여부 초기화" 라고 적는다 →
  분류를 먼저 고르고 라디오는 뒤에 누른다(확장 순서 그대로).
- 껍데기(`body`)가 처음부터 있어 준비 표식을 안 보고 들어가던 버그를 고쳤다(첫 시험: 4초 만에 경고 17개).
  보리보리(`formSelector: body` + `readySelector`)에도 같은 구멍이 있었다.
- 참고: 검증 도구(playwriter)는 이 프레임에서 30초 넘는 evaluate 를 "context destroyed" 로 끊는다
  (아무것도 안 하는 대조 실험도 같음, 문서는 그대로). 확장의 `executeScript` 와는 무관하다 — 채움을
  페이지 안에서 돌리고 짧게 조회해 확인했다.

저장·임시저장은 누르지 않았고 창은 닫았다. 부작용: 몰 이미지 저장소에 **시험 이미지 12장**
(세 번 × 4장, 상품으로는 올라가지 않음).

## 12. 남은 확인거리

1. 실제 확장으로 실제 상품 한 번(리로드 후, 1.0.83).
2. 상품정보제공고시 새 창 자동화 — 창이 값을 겉으로 어떻게 돌려주는지부터.
3. 샵바이 로그인 화면(자동 로그인) — 실측 전.
4. **주문수집** — 신규 주문이 없어 아직 못 봄(사장님, 2026-09-11).
