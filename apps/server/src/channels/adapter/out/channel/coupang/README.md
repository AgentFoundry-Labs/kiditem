# 쿠팡 WING 폼 · 엑셀 실측 사실

쿠팡 채널 어댑터와 확장의 WING 폼 채우기가 기대는, 라이브 화면과 양식 파일에서 잰 사실이다.
추론이 아니라 실측이므로 코드가 만드는 값이 이와 다르면 코드를 의심한다. 등록 실행 울타리는
몰 중립이고(ADR-0014 · KID-321), 여기 적힌 것은 쿠팡 어댑터 안의 사정뿐이다.

## 상품등록 폼(formV2)

- 카테고리를 골라야 나머지 섹션이 열린다(선택 전 `input` 14개 → 후 81개, 파일 입력 0 → 3). 자동화는 카테고리부터 한다.
- 이름 칸이 둘이다. 노출상품명과 등록상품명(판매자 관리용, 셀피아 상품명과 같은 모양)은 각각 최대 100자다.
- 브랜드와 제조사는 따로 있다. 자사 규약은 브랜드 칸을 비우고 `브랜드없음(또는 자체제작)` 을 체크하며, 제조사에 이름을 적는다.
- 옵션명 컬럼은 카테고리가 정한다. 값만 넣는다.
- 인증·신고 대상이 아니면 `인증대상아님` 을 명시로 골라야 한다.
- 배송 · 반품은 상품별 값이 아니라 계정에 설정된 출고지 · 반품지 주소록에서 고른다.
- 검색필터 단계는 없어졌다. 상품 속성(검색옵션)에 들어갔고, 채우면 노출이 최대 12% 늘어난다고 안내한다.
- 제출 버튼은 신규 `판매요청`, 수정 `수정 및 검수 요청` 이다. 우하단 `등록` 은 페이지 별점 위젯이라 누르지 않는다.
- 상세설명은 `HTML 작성` 탭에 저장한다. `이미지 업로드` 탭은 5,000px 에서 이미지를 자른다.
- 상품이미지 드롭존은 Dropzone.js 다. 드롭존에 `drop` 이벤트를 보내야 올라간다.

## 일괄등록 엑셀(V4.6)

원본은 `apps/web/public/coupang-wing-bulk-template-v4.6.xlsm` 이다. `기본` 시트(117컬럼)가 실제 등록 대상이고
헤더는 4행(그룹 · 컬럼명 · 필수 여부 · 설명)이다.

- 배송 · 반품 컬럼은 없다. 배송 관련은 `출고리드타임`(65, 필수, 1~99) 하나뿐이다.
- 노출상품명 컬럼도 없다. `등록상품명`(1)은 발주서에서만 쓰인다.
- 주요 0-based 컬럼: 브랜드 6 · 제조사 7 · 검색어 8(`/` 구분, 최대 20개) · 구매옵션 9~20 · 검색옵션(상품 속성) 21~60 ·
  판매가격 61 · 할인율기준가(정상가) 63 · 재고 64 · 바코드 74 · 인증∙신고 75~86(4칸 × 3블록) ·
  상품고시 카테고리 88 · 고시값 89~102 · 이미지 103~105 · 상세 설명 109(파일명 기재 방식만 안내).
- `hidden` 시트가 드롭다운 허용값의 원본이다. 인증∙신고 유형 첫 값은 `인증대상아님`, 바코드없음 사유는 5종이다.
